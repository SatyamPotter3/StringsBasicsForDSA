# Java String Basics

This repository contains my practice of **Java String basics** for DSA preparation.

## 📚 Topics Covered

* String Declaration
* `length()`
* `charAt()`
* String Traversal
* `toCharArray()`
* `equals()`
* `equalsIgnoreCase()`
* `toLowerCase()` / `toUpperCase()`
* `substring()`
* `indexOf()`
* `contains()`
* `replace()`
* `trim()`
* `split()`
* String Concatenation
* `StringBuilder`

## 🧩 Practice Questions

Some String-based problems are also solved to **strengthen these concepts and improve problem-solving skills**.

* Palindrome Check
* Character Frequency
* First Non-Repeating Character
* First Repeating Character
* Remove Duplicate Characters
* Anagram Check
* Reverse Words in a String
* String Rotation

## 🎯 Purpose

To revise and strengthen **Java String fundamentals** before moving on to more advanced String-based DSA problems.
